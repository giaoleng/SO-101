# Camera calibration workspace

Use this directory for camera setup notes and reference images.

- <code>reference/</code>: checkerboard / AprilTag capture examples, camera framing references, and before/after mounting photos.
- Device-specific intrinsic/extrinsic calibration outputs should remain local and are ignored by Git.

For the procedure and the distinction between image-policy camera setup and optional 3D geometric calibration, see [Camera calibration guide](../../docs/real-hardware/CAMERA_CALIBRATION.md).
